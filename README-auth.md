# 认证系统说明

这是一个基于SQLite3的简单登录和注册系统，暂时没有邮箱验证。该系统与Fashion Website电商网站项目集成。

## 功能特点

- 用户注册和登录
- 密码加密存储
- 会话管理
- 使用SQLite3数据库存储用户信息
- 安全的JSON解析和错误处理
- CORS支持和OPTIONS请求处理
- 登录状态持久化
- 用户中心页面
- 退出登录功能
- 与购物车系统集成

## 系统要求

- Node.js (14.x以上)
- npm (6.x以上)

## 安装与运行

1. 确保已安装Node.js和npm
2. 克隆或下载该项目
3. 在项目根目录运行以下命令：

```bash
# 运行启动脚本
./start.sh
```

或者手动执行：

```bash
# 安装依赖
npm install

# 启动服务器
node server.js
```

4. 服务器将在 http://localhost:3000 启动
5. 在浏览器中访问以下URL：
   - 注册页面: http://localhost:3000/html/auth/register.html
   - 登录页面: http://localhost:3000/html/auth/login.html
   - 用户中心: http://localhost:3000/html/user-center/index.html (需要先登录)

## 与电商网站的集成

认证系统与电商网站的集成主要体现在以下几个方面：

1. **导航栏用户状态**：所有页面顶部导航栏都会根据用户登录状态显示不同内容
2. **购物车同步**：登录用户的购物车信息会自动同步
3. **收藏商品**：登录用户可以收藏商品，并在用户中心查看
4. **订单管理**：登录用户可以查看和管理订单
5. **个人信息**：用户可以在用户中心管理个人信息

## 文件结构说明

- `server.js` - Express服务器和SQLite3数据库配置
- `src/html/auth/` - 登录和注册页面
- `src/js/modules/auth/` - 前端认证相关JS文件
  - `api.js` - API请求和会话管理
  - `validation.js` - 表单验证和提交处理
  - `session.js` - 会话状态管理和导航栏更新
- `src/html/user-center/` - 用户中心页面
- `users.db` - SQLite3数据库文件（首次运行时自动创建）

## 账户注册流程

1. 访问注册页面
2. 填写用户名、邮箱和密码
3. 点击注册按钮
4. 成功后跳转到登录页面

## 登录流程

1. 访问登录页面
2. 输入邮箱和密码
3. 点击登录按钮
4. 成功后跳转到用户中心页面

## 用户中心和登出功能

1. 登录成功后会跳转到用户中心页面
2. 用户中心页面显示用户信息和功能菜单
3. 在用户中心可以点击"退出登录"按钮登出账号
4. 登出后会清除会话信息并跳转到首页
5. 会话状态会在所有页面间保持（使用localStorage）

## 安全性说明

- 密码使用PBKDF2加密存储
- 使用随机生成的盐值增强安全性
- 简单的会话管理（使用localStorage）
- 安全的JSON解析和错误处理
- 添加CORS支持和预检请求处理
- 用户中心页面登录状态检查

## 排错指南

### 处理 "Unexpected end of JSON input" 错误

可能的原因:
1. 服务器返回的不是有效的JSON
2. 服务器没有设置正确的Content-Type头
3. 网络错误导致响应不完整

修复方法:
- 服务器强制设置Content-Type头为application/json
- 前端使用safeParseJSON函数安全解析JSON响应
- 增加了全面的错误捕获和日志记录

### 处理 "405 Method Not Allowed" 错误

可能的原因:
1. 前端使用的HTTP方法与服务器端预期的不一致
2. 服务器没有正确处理预检(OPTIONS)请求
3. 前端代码中存在API调用方法不一致

修复方法:
- 添加CORS中间件处理预检请求
- 明确指定API请求方法（GET、POST等）
- 统一前端API调用方式，避免直接fetch和API模块混用
- 添加请求日志帮助调试

### 处理登出按钮无响应问题

可能的原因:
1. 事件监听器绑定错误
2. 嵌套的DOMContentLoaded事件造成时序问题
3. JavaScript错误中断执行

修复方法:
- 移除嵌套的DOMContentLoaded事件
- 使用直接的onclick属性绑定事件
- 添加调试日志跟踪执行流程
- 确保DOM元素存在后再绑定事件

### 处理登录状态不持久问题

可能的原因:
1. 页面间没有共享登录状态检查逻辑
2. localStorage存储或读取有误
3. 导航栏状态没有正确更新

修复方法:
- 创建统一的会话管理模块
- 在所有页面使用相同的状态检查逻辑
- 添加导航栏用户状态更新函数
- 确保localStorage正确存储会话信息

## 注意事项

这只是一个简单的演示系统，在实际生产环境中，应该采用更完善的安全措施，例如：

1. 使用HTTPS确保传输安全
2. 实现登录失败次数限制
3. 添加双因素认证
4. 实现密码复杂度要求
5. 使用更安全的服务器端会话管理
6. 添加防CSRF和XSS保护
