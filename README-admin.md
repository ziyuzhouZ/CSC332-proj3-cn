# 管理员系统说明

这是Fashion Website电商网站的管理员后台系统，提供了管理员登录、注册和基本的管理功能，包括门店管理、销售数据分析和订单管理。

## 功能特点

- 管理员登录和注册
- 基于邀请码的注册系统
- 管理员权限验证
- 销售数据分析和图表展示
- 门店管理
- 订单处理和状态管理
- 登录状态持久化

## 使用方法

### 管理员登录

1. 访问管理员登录页面：`/html/admin/login.html`
2. 输入默认管理员账号密码:
   - 用户名: `admin`
   - 密码: `admin123`
3. 点击登录，成功后将跳转到管理员仪表盘

### 管理员注册

1. 访问管理员一次性注册页面：`/html/admin/register.html`
2. 填写表单信息，包括用户名、邮箱、密码和邀请码
3. 邀请码为: `6666`
4. 提交表单，注册成功后将跳转到管理员仪表盘

### 仪表盘功能

管理员仪表盘提供了电商系统的主要管理功能：

1. **销售概览**：显示总销售额、热销商品和销售趋势图表
2. **门店管理**：查看和管理商店信息和库存
3. **订单管理**：处理订单和更新订单状态
4. **用户管理**：查看和管理用户账户(开发中)

## 文件结构说明

- `src/html/admin/` - 管理员页面HTML文件
  - `login.html` - 管理员登录页面
  - `register.html` - 管理员注册页面
  - `dashboard.html` - 管理员仪表盘
  - `stores.html` - 门店管理页面
  - `store-detail.html` - 门店详情页面
  - `orders.html` - 订单管理页面
  - `sales.html` - 销售数据分析页面
  - `invite.html` - 邀请码管理页面
  
- `src/js/api/admin/` - 管理员API相关JS文件
  - `auth-interceptor.js` - 认证拦截器
  - `sqlite-invites.js` - 邀请码管理(SQLite版本)
  - `invites.js` - 邀请码管理

- `src/css/pages/admin.css` - 管理员页面样式

## 技术实现

本管理员系统使用以下技术实现：

1. **前端**:
   - 原生JavaScript
   - Chart.js (数据可视化)
   - CSS3 Flexbox和Grid布局
   
2. **后端**:
   - 邀请码验证(硬编码为6666)
   - 基于localStorage的会话管理
   - 简化的认证拦截器

3. **数据管理**:
   - 模拟API响应处理
   - 本地存储管理员信息
